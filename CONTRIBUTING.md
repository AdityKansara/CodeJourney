# Contributing to CodeJourney

Thank you for your interest in contributing to CodeJourney! This repository is a personal learning project built around algorithm practice and code solutions.

## How to contribute

1. Fork the repository.
2. Create a new branch for your work, using a descriptive name like `feature/add-1342-solution` or `fix/readme-typo`.
3. Add or improve solutions in the correct folder:
   - `Easy/`
   - `Medium/`
   - `Hard/`
4. Use the existing solution header format:
   - `# #Problem Number - Problem Name`
   - `# Problem solved by Adity`
   - `# Time Complexity: ...`
   - `# Space Complexity: ...`
5. Keep code simple, readable, and well-formatted.
6. Push your branch to GitHub.
7. Open a pull request (PR) or merge request (MR) against `main`.
   - Do not commit directly to `main`.
   - Use the PR/MR description to explain what changed and why.

## File naming

- Use a descriptive file name like `7.py`, `1342.py`, or `203.java`.
- Keep the numbering consistent with the problem number.

## Suggesting changes

- Add a new solution if you solve a problem that is not already included.
- Improve an existing solution by making it clearer or adding edge-case notes.
- Update `README.md` with better organization, examples, and tips.

## Code style

- Prefer Python 3 syntax for Python files.
- Keep Java code simple and self-contained.
- For Bash scripts, use standard shell conventions.

## Why contribute?

This repo is intended to help others learn from practice problems and clean solutions. Every improvement helps make the project more useful and easier to navigate.

## Notes

- Please do not copy full solutions from closed sources without attribution.
- If you reference a discussion or editorial, add a short note explaining the idea.
- Keep pull requests small and focused.
